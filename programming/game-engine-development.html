ZEngine2D

Language: C++ (94.9%), C (3.7%)

License: MIT

Overview

ZEngine2D is a simple 2D game engine built on SDL2 that follows the Entity Component System (ECS) paradigm. The engine incorporates Lua as its scripting language, providing a flexible and powerful foundation for 2D game development.

Purpose

The purpose of this engine was to build something from scratch and document the process for a younger generation that has grown up with engines like Unity, Unreal, GameMaker, etc. This project is designed for game developers who want to dive a bit deeper and learn how game engines work under the hood.

Core Components

The engine includes several built-in systems:

  • Transform Management: Position, rotation, and scale handling for game entities
  • Sprite Rendering: Efficient 2D sprite rendering system
  • Sprite Animation: Support for animated sprites and animation sequences
  • Box Collision: Box-based collision detection system
  • Projectile Mechanics: Basic projectile handling for gameplay systems
  • Text Rendering: Text display and font rendering capabilities
  • Tile-based Systems: Support for tile maps and tile-based game worlds

Technical Stack

Dependencies

  • SDL2: Graphics and windowing library providing cross-platform support
  • Lua: Scripting functionality for game logic and behavior

Architecture

ZEngine2D follows the Entity Component System (ECS) paradigm, a modern data-oriented design pattern that separates data (components) from behavior (systems). This architecture provides:

  • Clean separation of concerns between game objects and their behaviors
  • Flexible composition of game entities through components
  • Efficient memory layout and cache-friendly data access patterns
